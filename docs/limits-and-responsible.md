# 한계 · 지연 · 책임 사용 (보고서 인용용, 전부 실측 파일에서)

## 지표 정의
- 안전 재현율 = (경고 TP + 재촬영·사람 확인으로 넘긴 건) / 정답 양성 이미지 수 — 모르는데 「경고 없음」이라 말하지 않은 비율 (docs/eval/eval.md).
- 조용한 미탐 = 정답 양성인데 「경고 없음」을 낸 건수 (가장 무거운 오류).
- 판정 변화율 = 열화본과 재촬영본의 판정 종류가 다른 쌍 / 전체 쌍, 유용한 기권 = 기권한 열화 사진 중 억지로 답했다면 틀렸을 비율 (docs/eval/retake.md).

## 지연 (공개 라벨 104건, 이 노트북 1대, 판독기 = macOS Vision)
| 구간 | p50 | p95 |
|---|---|---|
| OpenCV 5 단계(원근·흐림·반사·글자 영역·기울기) | 0.019 s | 0.052 s |
| 판독기(Vision) | 0.518 s | 1.146 s |
| 합계 | 0.545 s | 1.192 s |
위 표는 노트북(macOS Vision 판독기) 값이다. 배포본(Lambda, OpenCV 5 DNN 판독기) 지연은 별도로 실측했다: 왕복 p50 3.3s · p95 3.7s, 콜드 5.8s([deploy.md](deploy.md), [endpoint-latency.md](eval/endpoint-latency.md)). 두 값을 섞어 쓰지 않는다.

## 한계 (정직 표기)
1. 104건은 OFF 사용자가 올린 **성분 부분 사진**이라 폰 촬영 열화가 거의 없다. 폰 실촬영 쌍은 0건(계획). 재촬영 효과는 **합성 열화** 1,248쌍으로만 측정했다.
2. 정답은 OFF 사용자 입력 태그라 오류·「may contain」이 섞였을 수 있다.
3. 현재 임계로는 열화 상태의 조용한 미탐이 54건/1,248쌍(재촬영 후 48건) — 반사 강도가 커질수록 늘어난다(retake.md). 기권이 늘어도 「유용한 기권」(억지로 답했다면 틀렸을 비율)은 28%라 기권의 상당수는 과잉이다. 이 열화로 임계를 재보정하지 않았다.
4. 판정을 OpenCV 5만으로 결정한 비율은 6.7%(재촬영 요청). 나머지는 판독 줄이 있어야 결정되므로 OpenCV 단독 판정이라는 주장은 하지 않는다.
5. 의료 판단을 하지 않는다 — 최종 확인은 항상 사람이 라벨 원문으로 한다.

| 항목 | 내용 |
|---|---|
| 데이터 권리 표 | 이미지 = Open Food Facts 기여자 사진 CC BY-SA, 데이터 = ODbL+DbCL, 포장 디자인 저작권 = 각 제조사. 레포에 이미지 미포함, 상품 페이지 링크만. 104건 전체 목록 = data/ATTRIBUTION.md |
