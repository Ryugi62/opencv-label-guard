- 실행: 이미지 열기·OpenCV·판독 오류로 못 돈 건 = **0건**
- 임계값(사전 고정 후 보정표로 확인): 흐림 < 15, 반사 > 0.4, 판독 신뢰도 < 0.6, 글자영역 최소 0
